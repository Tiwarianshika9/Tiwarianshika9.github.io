Canonical URL
-------------
https://www.anshikatiwari.in/

Upload all files and the assets/ folder to the public root of www.anshikatiwari.in.

Included
--------
- index.html
- robots.txt
- sitemap.xml
- site.webmanifest
- .htaccess (Apache: HTTPS + non-www canonical redirect, compression, headers, caching)
- 404.html
- assets/favicon.svg
- assets/apple-touch-icon.png
- assets/profile-avatar.png
- assets/og-image.png

IMPORTANT
---------
1. DNS/SSL must make both www.anshikatiwari.in and www.www.anshikatiwari.in reachable.
2. .htaccess redirects everything to https://www.anshikatiwari.in/ (non-www).
3. If your hosting uses Nginx, do NOT use .htaccess; configure the same redirect in Nginx.
4. After deployment, submit:
   https://www.anshikatiwari.in/sitemap.xml
   in Google Search Console.
5. Test structured data with Google's Rich Results Test / Schema Markup Validator.
6. The resume did not provide verified LinkedIn/GitHub/Instagram profile URLs.
   Add them later to the Person JSON-LD "sameAs" array and to visible social links.
